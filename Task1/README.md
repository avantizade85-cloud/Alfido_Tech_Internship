# Alfido Tech Internship - Task 1

## Zomato Restaurant & Review Data Analysis

### 📌 Project Overview

This project is completed as part of the **Alfido Tech Data Science Internship**.

The objective of this task is to analyze Zomato restaurant data and extract meaningful insights related to restaurant ratings, cuisines, locations, votes, pricing, online ordering and table booking.

The project uses Python-based data analysis and visualization techniques to clean the dataset, analyze important features and generate useful business recommendations.

---

## 🎯 Objectives

The main objectives of this project are:

- Clean and preprocess the Zomato dataset.
- Identify and handle missing values.
- Remove duplicate records.
- Analyze restaurant ratings.
- Analyze cuisines and their ratings.
- Identify restaurant location hotspots.
- Analyze price/cost and restaurant ratings.
- Analyze votes and restaurant popularity.
- Study online ordering and table booking.
- Generate data visualizations.
- Create a cuisine word cloud.
- Generate business recommendations.
- Save cleaned data and analysis results.
